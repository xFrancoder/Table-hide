# Table Hide

Hide and reveal markdown table cells for active recall and language learning in Obsidian.

Oculta y revela celdas de tablas Markdown para práctica de memoria activa y aprendizaje de idiomas en Obsidian.

![Demo](assets/demo.mp4)

---

## What is this?

Table Hide lets you hide and reveal Markdown table cells with a single click.

It is designed for active recall, language learning, vocabulary practice, and any workflow that benefits from hiding information while studying.

You can:

- Hide or reveal all table cells with one button.
- Click individual cells to reveal or hide them.
- Lock or unlock columns with **Alt + Click** on a column header.
- Lock or unlock rows with **Alt + Click** on the first cell of a row.
- Locked rows and columns remain visible when using **Hide All**.
- Locked rows and columns are highlighted with a subtle background color.

- Toggle hide/show all table cells.


Then enable the plugin.

### Manual Installation

Copy:

```txt
main.js
manifest.json
styles.css
```

into:

```txt
.obsidian/plugins/table-hide/
```

Then restart Obsidian and enable the plugin.

---

## Usage

### Hide or reveal a cell

Click any table cell to hide or reveal its content.

### Lock or unlock a column

Hold **Alt** and click a column header.

The entire column will remain visible when using **Hide All**.

### Lock or unlock a row

Hold **Alt** and click the first cell of a row.

The entire row will remain visible when using **Hide All**.
